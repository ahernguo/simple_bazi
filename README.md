# 專案說明

以《徐玉蘭的人生八字應用課》來整理內容，搭配 MAUI 提供 Windows, iOS, Android 跨平台之應用程式

部分內容是搭配 Google Gemini 3.1 Pro 所產生的描述且含有個人解讀，可能會與上課影片稍有不同

判讀上以窮舉的方式來列出所有可能性，預計未來會加入 AI 自動判讀功能
